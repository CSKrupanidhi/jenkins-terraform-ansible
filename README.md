# Jenkins Terraform Ansible AWS Project

## Project Objective

Automate AWS EC2 provisioning using Terraform
and configure the EC2 instance using Ansible.

## Technologies

- Jenkins
- Terraform
- Ansible
- AWS EC2
- GitHub
- Linux

## Pipeline Workflow

1. Checkout source code from GitHub.
2. Validate Terraform confixguration.
3. Create AWS infrastructure.
4. Capture EC2 public IP.
5. Configure EC2 using Ansible.
6. Verify Nginx deployment.
